# Repository Layout

| Path | Contents |
| --- | --- |
| `bin/` | Helper scripts installed to `~/.local/bin` (`rice-*`, `waybar-set`, `hypr-set`, etc.) |
| `quickshell/` | Quickshell apps (`rice-desktop`, `rice-settings`, `rice-welcome`, `rice-lockscreen`, `rice-apps`, `rice-scene`) |
| `config/` | Dotfiles installed to `~/.config` (Hyprland, Waybar, Kitty, Rofi, etc.; niri config is generated by `bin/rice-niri`) |
| `lua/` | Hyprland Lua add-ons (keybinds, Infinite Desktop, gestures, gaming rules, window rules) |
| `install/` | Installer helpers, distro detection (`install/gentoo.sh`), and SHA-256 `checksums.txt` |
| `install.sh` | Interactive installer and updater (`install`, `update`, `choose`, `restore`) |
| `sync.sh` | Copies your local config/settings back into the repo (sanitizing `$HOME` to `@HOME@` and scanning for secrets) |
| `settings/` | Default and synced shell settings JSON files |
| `sddm/` | Material 3 SDDM login screen theme |
| `wallpapers/` | Default wallpapers copied to `~/Pictures/Wallpapers` |
| `sounds/` | CC0 UI and notification sounds |
| `community/` | Community themes index (`index.json`) and submission guide |
| `nix/`, `flake.nix` | NixOS module and flake definition |
| `tests/` | Automated test suite (`security.sh`, `qml-shared.sh`, `qml-syntax.sh`, `dock.sh`, `gentoo.sh`, `infinite.sh`, `sddm.sh`, `hotcorner.py`) |
| `docs/` | Multilingual documentation (`en` in root, `es/`, `pt/`) |
| `.github/` | CI workflows (`ci.yml`, `release.yml`), PR template, and issue templates |
| `VERSION` | Current shell version used by update checks |

## Syncing your setup

`./sync.sh` copies your current configuration from your machine into the repository (replacing `$HOME` with `@HOME@` and checking for secrets), while `./install.sh` applies `settings/` on other machines without overwriting customized local files (`./install.sh --update --use-saved-settings` forces saved settings).

For branching, PRs, and releasing versions, see [CONTRIBUTING.md](../CONTRIBUTING.md).
