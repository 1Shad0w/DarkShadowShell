# Keybinds

`SUPER` is the main modifier. On **niri**, all shell keybinds work identically, with niri's column bindings (`SUPER + R` width, `SUPER + F` maximize, `SUPER + [` / `]` column) in place of Hyprland layout keys. Press `SUPER + /` (Hyprland) or `SUPER + Shift + /` (niri) anytime for an on-screen cheat sheet.

---

## Essentials

| Keys | Action |
| --- | --- |
| `SUPER + U` | Open **Settings** |
| `SUPER + Return` | Open terminal |
| `SUPER + E` | Open file manager |
| `SUPER + R` | Open app menu |
| `ALT + Space` | Open DarkShadow Launcher |
| `SUPER + W` | Open wallpaper picker |
| `SUPER + L` | Lock screen |
| `SUPER + M` | Exit Hyprland |
| `SUPER + /` | Show all keybinds |

## Windows & Workspaces

| Keys | Action |
| --- | --- |
| `SUPER + Q` | Close active window |
| `SUPER + ←/→/↑/↓` | Move focus |
| `SUPER + left mouse` | Drag window |
| `SUPER + right mouse` | Resize window |
| `SUPER + SHIFT + V` | Toggle floating |
| `SUPER + P` | Pseudo-tile |
| `SUPER + J` | Toggle split direction |
| `SUPER + T` | Stack windows (tabs) |
| `SUPER + H` / `SUPER + SHIFT + H` | Minimize / restore window |
| `SUPER + 1 … 0` | Switch to workspace |
| `SUPER + SHIFT + 1 … 0` | Move window to workspace |
| `SUPER + scroll` | Next / previous workspace |
| `SUPER + S` | Toggle scratchpad |

## Shell Panels, Widgets & Tools

| Keys | Action |
| --- | --- |
| `SUPER + A` | Control Center (quick switches) |
| `SUPER + N` | Control Center (notifications) |
| `SUPER + V` | Clipboard history |
| `SUPER + G` | Game bar overlay |
| `SUPER + X` | Toolbox (tasks, notes, timer, converter, chat) |
| `SUPER + ALT + W` | Edit desktop widgets |
| `SUPER + ALT + D` | Today & System card (Dynamic Island) |

## Audio, Media & Hardware

| Keys | Action |
| --- | --- |
| `ALT + ]` / `ALT + [` | Volume up / down |
| `SUPER + F12` / `F11` / `F10` | Volume up / down / mute (OSD) |
| Media keys | Play/pause, next, previous |
| `Fn` / headset `+` `-` | Volume, mute, mic, brightness |

## Screenshots & Recording

| Keys | Action |
| --- | --- |
| `Print` / `SUPER + SHIFT + S` | Screenshot region |
| `SHIFT + Print` | Screenshot entire screen |
| `SUPER + SHIFT + R` | Record region (press again to stop) |

## Infinite Desktop & Touchpad

| Keys / Gesture | Action |
| --- | --- |
| `SUPER + F` | Toggle Infinite Desktop |
| `SUPER + ALT` + mouse / touchpad | Pan canvas live |
| `SUPER + ALT + Arrows` | Pan canvas by step |
| `SUPER + CTRL + Arrows` | Glide to next window in direction |
| `CTRL + Mouse wheel` / 2-finger pinch | Zoom in / out around pointer |
| `SUPER + Mouse wheel` / 2-finger scroll | Pan canvas vertically / horizontally |
| `SUPER + ALT + 0` | Reset zoom to 100% |
| 3-finger / 4-finger swipes & pinches | Configurable in **Settings → Desktop → Touchpad gestures** |
