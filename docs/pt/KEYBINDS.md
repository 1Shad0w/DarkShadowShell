# Atalhos de teclado

`SUPER` é a tecla modificadora principal. No **niri**, todos os atalhos próprios do shell funcionam igualmente, com os atalhos de coluna do niri (`SUPER + R` largura, `SUPER + F` maximizar, `SUPER + [` / `]` coluna) no lugar das teclas de layout do Hyprland. Pressione `SUPER + /` (Hyprland) ou `SUPER + Shift + /` (niri) a qualquer momento para ver a lista na tela.

---

## Essenciais

| Teclas | Ação |
| --- | --- |
| `SUPER + U` | Abrir **Configurações** |
| `SUPER + Return` | Abrir terminal |
| `SUPER + E` | Abrir gerenciador de arquivos |
| `SUPER + R` | Abrir menu de aplicativos |
| `ALT + Space` | Abrir DarkShadow Launcher |
| `SUPER + W` | Abrir seletor de papéis de parede |
| `SUPER + L` | Bloquear tela |
| `SUPER + M` | Sair do Hyprland |
| `SUPER + /` | Mostrar todos os atalhos |

## Janelas e workspaces

| Teclas | Ação |
| --- | --- |
| `SUPER + Q` | Fechar janela ativa |
| `SUPER + ←/→/↑/↓` | Mover o foco |
| `SUPER + clique esquerdo` | Arrastar janela |
| `SUPER + clique direito` | Redimensionar janela |
| `SUPER + SHIFT + V` | Alternar flutuante |
| `SUPER + P` | Pseudo-tile |
| `SUPER + J` | Alternar direção da divisão |
| `SUPER + T` | Empilhar janelas (abas) |
| `SUPER + H` / `SUPER + SHIFT + H` | Minimizar / restaurar janela |
| `SUPER + 1 … 0` | Ir para workspace |
| `SUPER + SHIFT + 1 … 0` | Mover janela para workspace |
| `SUPER + scroll` | Próximo / anterior workspace |
| `SUPER + S` | Mostrar / ocultar scratchpad |

## Painéis, widgets e ferramentas

| Teclas | Ação |
| --- | --- |
| `SUPER + A` | Central de controle (chaves rápidas) |
| `SUPER + N` | Central de controle (notificações) |
| `SUPER + V` | Histórico da área de transferência |
| `SUPER + G` | Game bar |
| `SUPER + X` | Caixa de ferramentas (tarefas, notas, timer, conversor, chat) |
| `SUPER + ALT + W` | Editar widgets de desktop |
| `SUPER + ALT + D` | Cartão Hoje & Sistema (Ilha Dinâmica) |

## Áudio, mídia e hardware

| Teclas | Ação |
| --- | --- |
| `ALT + ]` / `ALT + [` | Aumentar / diminuir volume |
| `SUPER + F12` / `F11` / `F10` | Aumentar / diminuir / silenciar volume (OSD) |
| Teclas de mídia | Reproduzir/pausar, próxima, anterior |
| `Fn` / botões `+` `-` do headset | Volume, mudo, microfone, brilho |

## Capturas e gravação

| Teclas | Ação |
| --- | --- |
| `Print` / `SUPER + SHIFT + S` | Capturar região |
| `SHIFT + Print` | Capturar tela inteira |
| `SUPER + SHIFT + R` | Gravar região (pressione novamente para parar) |

## Infinite Desktop e Touchpad

| Teclas / Gesto | Ação |
| --- | --- |
| `SUPER + F` | Alternar Infinite Desktop |
| `SUPER + ALT` + mouse / touchpad | Mover a tela ao vivo |
| `SUPER + ALT + Setas` | Mover a tela em passos |
| `SUPER + CTRL + Setas` | Deslizar para a próxima janela na direção |
| `CTRL + scroll` / pinça de 2 dedos | Zoom in / out ao redor do ponteiro |
| `SUPER + scroll` / scroll de 2 dedos | Mover a tela vertical / horizontalmente |
| `SUPER + ALT + 0` | Redefinir zoom para 100% |
| Gestos de 3 / 4 dedos | Configuráveis em **Configurações → Desktop → Gestos do touchpad** |
