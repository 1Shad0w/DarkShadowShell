# Atajos de teclado

`SUPER` es la tecla modificadora principal. En **niri**, todos los atajos propios del shell funcionan igual, usando las teclas de columnas de niri (`SUPER + R` ancho, `SUPER + F` maximizar, `SUPER + [` / `]` columna) en lugar de las de diseño de Hyprland. Pulsa `SUPER + /` (Hyprland) o `SUPER + Shift + /` (niri) en cualquier momento para ver la guía en pantalla.

---

## Esenciales

| Teclas | Acción |
| --- | --- |
| `SUPER + U` | Abrir **Ajustes** |
| `SUPER + Return` | Abrir terminal |
| `SUPER + E` | Abrir gestor de archivos |
| `SUPER + R` | Abrir menú de aplicaciones |
| `ALT + Space` | Abrir DarkShadow Launcher |
| `SUPER + W` | Abrir selector de fondos |
| `SUPER + L` | Bloquear pantalla |
| `SUPER + M` | Salir de Hyprland |
| `SUPER + /` | Mostrar todos los atajos |

## Ventanas y espacios de trabajo

| Teclas | Acción |
| --- | --- |
| `SUPER + Q` | Cerrar ventana activa |
| `SUPER + ←/→/↑/↓` | Mover el foco |
| `SUPER + clic izquierdo` | Mover ventana |
| `SUPER + clic derecho` | Redimensionar ventana |
| `SUPER + SHIFT + V` | Alternar ventana flotante |
| `SUPER + P` | Pseudo-mosaico |
| `SUPER + J` | Cambiar dirección de división |
| `SUPER + T` | Apilar ventanas (pestañas) |
| `SUPER + H` / `SUPER + SHIFT + H` | Minimizar / restaurar ventana |
| `SUPER + 1 … 0` | Ir al workspace |
| `SUPER + SHIFT + 1 … 0` | Mover ventana al workspace |
| `SUPER + rueda` | Workspace siguiente / anterior |
| `SUPER + S` | Mostrar / ocultar scratchpad |

## Paneles, widgets y herramientas

| Teclas | Acción |
| --- | --- |
| `SUPER + A` | Centro de control (interruptores rápidos) |
| `SUPER + N` | Centro de control (notificaciones) |
| `SUPER + V` | Historial del portapapeles |
| `SUPER + G` | Game bar |
| `SUPER + X` | Caja de herramientas (tareas, notas, temporizador, conversor, chat) |
| `SUPER + ALT + W` | Editar widgets de escritorio |
| `SUPER + ALT + D` | Tarjeta de Hoy y Sistema (Isla Dinámica) |

## Audio, multimedia y hardware

| Teclas | Acción |
| --- | --- |
| `ALT + ]` / `ALT + [` | Subir / bajar volumen |
| `SUPER + F12` / `F11` / `F10` | Subir / bajar / silenciar volumen (OSD) |
| Teclas multimedia | Reproducir/pausar, siguiente, anterior |
| `Fn` / botones `+` `-` de auriculares | Volumen, silencio, micrófono, brillo |

## Capturas y grabación

| Teclas | Acción |
| --- | --- |
| `Print` / `SUPER + SHIFT + S` | Captura de región |
| `SHIFT + Print` | Captura de pantalla completa |
| `SUPER + SHIFT + R` | Grabar región (pulsar de nuevo para detener) |

## Infinite Desktop y Touchpad

| Teclas / Gesto | Acción |
| --- | --- |
| `SUPER + F` | Activar / desactivar Infinite Desktop |
| `SUPER + ALT` + ratón / touchpad | Mover el lienzo en vivo |
| `SUPER + ALT + Flechas` | Mover el lienzo por pasos |
| `SUPER + CTRL + Flechas` | Deslizar hacia la siguiente ventana en esa dirección |
| `CTRL + rueda` / pellizco 2 dedos | Acercar / alejar zoom alrededor del puntero |
| `SUPER + rueda` / scroll 2 dedos | Mover el lienzo vertical / horizontalmente |
| `SUPER + ALT + 0` | Restablecer zoom al 100 % |
| Deslizamientos y pellizcos de 3/4 dedos | Configurables en **Ajustes → Escritorio → Gestos del touchpad** |
